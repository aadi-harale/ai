# SafeShift — SIH26191

HackHabitat-inspired proactive relocation decision studio.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:8765`.

## Pages
- `/` — editorial landing page
- `/explore` — interactive relocation workspace
- `/brief` — printable decision brief

## Core differentiators
1. **Functional Carrying Capacity** — a candidate site supports only as many people as its weakest essential service can sustain.
2. **Low-Regret Relocation** — stress-test sites under heavier rainfall, road failure, and population growth.
3. **Site Viability Upgrade Planner** — simulate the smallest infrastructure package that can unlock a safer site.
4. **Community Cohesion + Consent Gate** — optimization cannot scatter neighbourhoods or bypass consent.

## Demo honesty
Malin is used as a real study location. Candidate sites, household clusters, capacities, costs, hazard polygons and scores in this demo are illustrative and must not be represented as an official relocation study.
